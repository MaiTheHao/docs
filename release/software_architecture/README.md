# Software Architecture - Kiến Trúc Phần Mềm

Tài liệu trong danh mục này bao gồm các kiến thức tổng hợp, nguyên lý và mẫu thiết kế kiến trúc phần mềm đã được rà soát và chuẩn hóa.

## Mục lục Danh mục

1. **[00. Fundamentals](00_fundamental/)** - Kiến thức nền tảng: Bối cảnh kiến trúc, 4 chiều (Characteristics, Components, Style, Decisions) và các quy luật đánh đổi trong thiết kế.
